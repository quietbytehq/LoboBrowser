# Logo

| File | Use |
| --- | --- |
| `lobster-logo.png` | Master glossy artwork |
| `icons/lobster-{16..512}.png` | App icon sizes (Linux desktop, Snap) |
| `icons/lobster.ico` | Windows app icon (16–256 px) |
| `lobster-mark.svg` | Flat one-colour mark for the toolbar, throbber and small sizes; uses `currentColor` |
| `icons/lobster-mark-dark-*.png` | Flat mark, dark ink for light themes (16, 24, 32 px) |
| `icons/lobster-mark-light-*.png` | Flat mark, light ink for dark themes (16, 24, 32 px) |

The glossy icon loses detail below 48 px; use the flat mark there.
